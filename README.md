# FoodMunch - Responsive Restaurant Website  

FoodMunch is a responsive website designed for a fictional restaurant, built using HTML and CSS to showcase menu items and enhance user experience.  

## 🚀 Demo  

Check out the live demo here: [FoodMunch Demo](https://saicharanp1.ccbp.tech)  

## 🛠 Features  

- **Responsive Design**: Optimized layout for various screen sizes.  
- **Custom Fonts & Styling**: Utilizes Google Fonts with a unique color scheme.  
- **User-Friendly Navigation**: Easy and intuitive browsing experience.  
- **Custom Components**: Unique buttons, section headers, and card designs for menu items and promotions.  

## 💻 Technologies Used  

- HTML5  
- CSS3  
- Google Fonts  

## 🌐 Fonts and Icons  

This project incorporates various Google Fonts for a visually appealing design, such as:

## 📚 Sections Included  

1. **Banner Section**: Features the main banner image and text.  
2. **Why Choose Us (WCU)**: Highlights reasons to choose FoodMunch.  
3. **Explore Menu**: Showcases popular food items.  
4. **Healthy Food Section**: Promotes healthy eating options.  
5. **Delivery and Payment**: Information about delivery and payment methods.  
6. **Follow Us**: Social media links for connection.  
7. **Footer**: Contains contact information and links.
